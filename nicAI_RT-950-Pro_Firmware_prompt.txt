the display is a ST7789 controller with a parallel interface.
the display is a portrait orientation with a resolution of 240x320 pixels.
the display panel operates inverted, so the ST7789 controller needs to be set inverted to attain normal color operation


The 4MB flash chip is a standard W25Q32 and follows the stadard protocol for that family of chips.


The SI4732 is as standard, information on operation is freely available from the manufacturer and various online resources.


the Radio SOCs are BK4829 series chips, the radio utilizes deal chips, with BK4829A responsible for operation on VHF,
BK4829B is responsible for operation on UHF and HF.
When operating on HF, the RELAY must be set high to properly route the signal through the HF filter stage.
The relay MUST be set low when operating the the Si4732 this makes it impossible to monitor HF frequencies on the BK4829B
simultaneously. Many radios implement an "interrupt" mechanism when the Si4732 is active to temporarily switch to regular
BK4829 radio mode when activity on the normal radio mode is detected. This cannot be done with HF BK4829B operation.

There is documentation for the BK4829 series chips available, and the PDF for the register table is attached, however, there
are undocumented registers and register bits, so there follows a set of register setting values that were captured from
a working radio, to provide reference values for proper operation.

Create various size fixed width fonts for the user interface and implement them appropriately in the user interface.
implement squelch tones as per the PDF for receive and transmit operations.
implement bandwidth control for receive and transmit operations.
you may utilize the W25Q32 flash memory for storing configuration settings and other persistent data, the addressing I'll leave up to you.

The attached project is a correctly configured Keil project already setup for the MCU being used in the radio, use this project to implement the firmware source code.
The MCU is an ArteryTek AT32A403AVGT7 and is able to run at 200 MHz, it should be configured at this speed.

There is a 0x800 byte reserved area at the start of RAM, use this to clone and relocate the vector table (VTOR) for interrupt handling.

In the main project folder is a PDF (BK4829.Registers.Table.pdf) listing all documented registers for the BK4829 chip.

Information on all other hardware is freely available online.
